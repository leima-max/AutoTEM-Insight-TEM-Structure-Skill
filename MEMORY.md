# Project Memory

This file stores long-term, durable memory for the AutoTEM-Insight / TEM-Structure Skill project. Daily notes belong in `memory/YYYY-MM-DD.md`; only information that should remain valid across future sessions belongs here.

## Memory Rules

- Use two layers of memory:
  - `memory/YYYY-MM-DD.md` records daily running notes, events, decisions, corrections, and timestamped context.
  - `MEMORY.md` records long-term information that should remain valid across sessions.
- If the user says "记住这个", corrects the assistant, establishes a new lesson, makes an important decision, or creates an important project time point, write it to files promptly.
- Do not rely only on chat history for durable memory.
- Prefer concise, factual entries. Separate facts from assumptions or suggestions.
- When a daily note becomes long-term project context, summarize it here and keep the detailed trail in the daily note.
