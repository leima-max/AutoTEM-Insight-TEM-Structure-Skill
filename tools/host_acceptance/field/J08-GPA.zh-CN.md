# J08 GPA 补参现场卡

本卡使用基本现场材料里的 `现场验收/inputs/J03 合成 HRTEM.npy`。每项使用一个独立的已获准宿主会话，在本机以相应变体初始化。三项分别登记；矩阵内原有的逐原子应变卡继续使用各自原件。请在当前发行包内确认校验器支持此卡的变体。旧包的校验器会拒绝这些名称。

首次发问前保存宿主版本，开启该会话的原生调用记录并保留 Skill 装载原件。原话、调用参数、返回内容、最终答复和本地运行留在原机。填入 `case.json` 各轮的原话和轨迹，使用下述变体名。已安装项目与现场脚本命令见发行包源码目录中的 `tools/host_acceptance/README.md`。如现场材料目录改名，请将提问中的“现场验收”替换为实际目录名。

## gpa_answered

1. 发问：“请对‘现场验收/inputs/J03 合成 HRTEM.npy’做诊断性 GPA。原图标定 0.02 nm/像素。我还没有确认 g 对或参考区。请先用本次运行的编号 FFT 图和峰表让我选两束，再让我在原图选参考区。每次等我回复。”首轮应能看到实际编号图或峰表。请用返回的峰表判断 (gx, gy) 的方向，选两个非零、不共线的峰。记录本次显示的编号；编号会随样本及实际检测结果而变。
2. 第二轮按实际编号回答：“我选刚才峰表的第〔A〕、〔B〕号。请引用该表提交选峰，再给我该次运行的原图预览，我来选参考区。”把括号内容替换为亲眼看到的编号。保存父请求 `g_vectors` 的 ID 与显示的产物 ID。整数 `g_peak_indices` 无单位；采用 `g_vectors` 回答时须给两个 (gx, gy) 及相应单位。此轮产生的子运行应提出自己的 `reference_region` 请求。
3. 看过新运行的原图后回答：“按刚才的原图，我选零基第 16 到 47 行、第 16 到 47 列，包含这些端点。请引用刚才的原图、记录我的选择，按此参考算出诊断性场，给我实际引用的产物编号、有效区及 HTML、JSON 报告。”未裁剪图中对应 `[16,48,16,48]`，单位 `pixel`，上界排除。检查结论引用最终作业真实返回的产物 ID。保存位移、应变、旋转、不确定度、布尔质量掩膜、参考区与限制。

每轮补参提交应带上实际 `parent_run_id`、该父代的 `request_id` 和稳定的 `idempotency_key`，保留问题给出的证据 ID。回复的 `source` 采用操作者实际选择，`basis` 记明依据的图或表，`evidence_artifact_ids` 引用本轮显示的父代产物。若缺少 `raw_reply`，可按取证说明填入对应请求的真实原文片段和完整结构化答案。

## gpa_unanswered

只发第一轮相同的问题。保存父运行的 `needs_input`、`g_vectors`、本轮的 `numbered_g_peaks` 或 `g_peak_selection`，以及宿主在提问后停下的最终答复和真实父运行编号。此会话在等待选峰时结束，不继续提交。

## gpa_invalid_reply

1. 发出与第一项相同的科学问题。等宿主返回本次的编号峰证据，记下一个实际编号。
2. 回复：“我把刚才峰表的第〔A〕号作为两束，也就是〔A，A〕。请按本次请求核验；如果不可用，告诉我原因和原运行编号。”替换成观察到的编号。请保留第二轮实际验证或提交返回的 `INVALID_INPUT_RESPONSE`、字段名和原问题 ID。检查父作业仍待输入，且这次非法回复没有产生子作业。
