# Runtime Contracts (A2)

This document defines the stable machine-readable runtime contracts emitted by the A2 workflow.

## `run_summary.json`

`run_summary.json` is serialized from `RunSummary` (`autotem.core.models.RunSummary`).

Required top-level fields:

| Field | Type | Description |
|---|---|---|
| `schema_version` | string | Core schema version (`0.1.0`). |
| `status` | string | Overall workflow status. |
| `workflow_name` | string | Effective workflow name. |
| `input_path` | string | Input path passed to workflow run. |
| `workflow_path` | string | Workflow recipe path (empty when using default). |
| `output_dir` | string | Output directory for this run. |
| `report_path` | string | `analysis_report.json` path. |
| `log_path` | string | `run.log` path. |
| `workflow_used_path` | string | `workflow_used.yaml` path. |
| `workflow_parameter_schema_version` | string | Parameter schema contract version. |
| `steps` | list[`RunSummaryStep`] | Step-by-step status and warnings. |
| `warnings` | list[string] | Unique warnings across run. |
| `warning_count` | integer | Count of unique warnings. |
| `runtime` | object | Runtime metadata (Python/version/platform/timestamp). |
| `input_fingerprint` | object | Input file path/hash/size info. |
| `workflow_fingerprint` | object | Effective workflow hash and path. |
| `workflow_parameters_snapshot` | object | Frozen parameters used for run. |
| `bc_interface_summary` | object | B/C interface completeness summary (`total/passed/missing/pass_rate/by_owner`). |

`RunSummaryStep` fields:

| Field | Type | Description |
|---|---|---|
| `name` | string | Workflow step name. |
| `status` | string | `pending/running/done/warning/failed/skipped`. |
| `warnings` | list[string] | Warnings generated by step. |
| `warning_count` | integer | Warning count for this step. |

## `run.log`

`run.log` is newline-delimited JSON (JSONL).  
Each line is serialized from `RunLogEntry` (`autotem.core.models.RunLogEntry`).

`RunLogEntry` fields:

| Field | Type | Description |
|---|---|---|
| `timestamp_utc` | string | ISO8601 UTC timestamp. |
| `level` | string | `DEBUG/INFO/WARNING/ERROR`. |
| `message` | string | Human-readable event message. |
| `context` | object | Structured metadata for this event. |

Parsing expectations:

- Consumers should parse line-by-line as independent JSON objects.
- Unknown future keys should be ignored by downstream consumers.
- Lines must remain valid JSON objects even when message text contains punctuation.
